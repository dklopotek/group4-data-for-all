# Rendering the Mycorrhizal Barcelona video

This Remotion project produces a 60-second, 1080×1080 square video for the
Mycorrhizal Barcelona pitch deck. Six scenes × ten seconds × thirty fps =
1800 frames. No audio. Subtitle-only.

## Compositions registered (`src/Root.tsx`)

| ID                | Duration   | Purpose                                               |
| ----------------- | ---------- | ----------------------------------------------------- |
| `MycorrhizalBCN`  | 60 s       | The main planner-pitch video (default render target). |
| `Amanita`         | 4 s        | Original mushroom-growth study, kept for reference.   |

## Render the main video

From `my-video/`:

```bash
npx remotion render MycorrhizalBCN out/mycorrhizal-bcn.mp4
```

This produces an H.264 MP4 at 1080×1080, 30 fps. Add `--codec=prores`
or `--codec=h265` if a different encoding is needed.

For a quick preview at quarter resolution (faster):

```bash
npx remotion render MycorrhizalBCN out/preview.mp4 --scale=0.5
```

Render a single still frame to sanity-check a scene:

```bash
# 1-second mark of Scene 3 (Scene 3 starts at 20s = frame 600)
npx remotion still MycorrhizalBCN out/scene3.png --frame=630 --scale=0.5
```

## Live preview (Studio)

```bash
npm run dev
# or: npx remotion studio
```

Then open the listed URL and select **MycorrhizalBCN**.

## Data dependencies

The top-15 priority zones live in `src/data/priorityZones.ts`. They were
hand-transcribed from `../outputs/priority_zones.csv` (relative to the repo
root) so the Remotion bundle does not have to read the CSV at build time.

If the CSV is regenerated by the NEXUS-Micro pipeline, regenerate
`src/data/priorityZones.ts` to match. The fields used by the composition
are: `rank`, `cellId`, `district`, `barri`, `sealedPct`, `lstAnomalyC`,
`meanNdvi`, `compositeB`, `intervention`. All other CSV fields are
ignored.

The grid coordinates `gx` and `gy` are derived from the `cell_id`
(`Cxx_yy` → `(xx, yy)`) by `parseCell` in `priorityZones.ts`; no
georeferencing is performed — the layout is a stylised abstraction.

The sensitivity-comparison Jaccard value (`1.00`) and the three weight
schemes shown in Scene 4 are constants set in
`src/scenes/Scene4_Robustness.tsx`. Update them there if the underlying
sensitivity result changes.

## Performance notes

- All animation is driven by `interpolate(frame, …, { easing })`. No
  CSS transitions, no Tailwind animation classes — both are forbidden in
  Remotion.
- `Easing.bezier(0.22, 1, 0.36, 1)` is used pervasively for soft enters.
  Constants live in `theme.ts`.
- SVG is the rendering primitive of choice for the map and barrier
  washes — fast, deterministic, and resolution-independent.
- Each scene's start and duration frames are passed in as props from the
  master composition rather than computed from `useCurrentFrame()`
  globally; this keeps each scene's animations local-frame-relative
  inside its own `<Sequence>`.
