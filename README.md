# Group 4 — Data For All

Seminar project repository.

## Getting started

1. Fill in [`docs/problem-brief.md`](docs/problem-brief.md) — one page, plain English, today
2. Each team member clones this repo and works on a branch
3. Pull requests for everything — no direct pushes to `main`

## Structure

```
docs/          project documentation and briefs
data/          raw and processed datasets (add large files to .gitignore)
notebooks/     analysis and exploration
output/        final visualisations and exports
```
